## Problem-Solving Approach

For important problems, I focus on understanding:

1. **Problem Statement**
2. **Brute Force Approach**
3. **Optimized Approach**
4. **Algorithm / Pattern Used**
5. **Time Complexity**
6. **Space Complexity**
7. **Edge Cases**

The goal is not only to solve problems but also to understand **why the solution works**.
